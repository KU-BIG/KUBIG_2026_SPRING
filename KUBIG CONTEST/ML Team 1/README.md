# 🌊 전국 단위 홍수 발생 후 수인성 감염병 예측 모델

저희 ML1팀은 환경 공공데이터를 활용하여 기후 재난 이후 수인성 감염병 발생을 예측하는 데이터 기반 조기경보 모델을 구축하였습니다.

기후변화로 폭우·홍수·침수와 같은 극단적 기상 현상이 증가하는 상황에서,
환경 변화가 감염병 발생에 어떤 영향을 주는지 정량적으로 분석하고
감염병 위험을 사전에 예측하는 것을 목표로 프로젝트를 진행했습니다.

## 📌 프로젝트 개요

주제
전국 단위 홍수 발생 후 수인성 감염병 발생 예측 모델

핵심 연구 질문
- 폭우 및 침수 이후 감염병은 몇 주 뒤 증가하는가?
- 환경 데이터를 활용해 다음 주 감염병 발생 위험을 예측할 수 있는가?

수인성 감염병은 오염된 물을 통해 전파되는 질병으로,
홍수 → 하수 역류 → 식수 오염이라는 경로로 확산될 가능성이 높습니다.

## 주요 Feature (X)

1️⃣ 강수 변수

인구가중 평균 강수량 (rain_nat)
극한 강수 노출 인구 비율 (ERER)
강수량 변화율 (rain_diff)

2️⃣ 침수 변수

전국 침수 면적 합계
침수 인구 노출 비율

3️⃣ 병원체 생존 환경

기온, 습도
수질지표(DO, COD, pH, 대장균 수 등)

4️⃣ 계절성 통제

월 더미 변수

👉 모든 변수를 전국·주 단위로 통합 및 인구가중 평균화하여 생성

## ⚠️ 한계점 (Limitations)

- 전국 단위 주간 데이터 사용으로 지역별 감염 특성과 세부 변동을 충분히 반영하지 못함
- 환경 변수와 감염병 간 관계는 인과가 아닌 상관관계 수준의 해석에 제한됨
- 감염병의 강한 계절성이 환경 변수 효과를 일부 가릴 가능성 존재
- 원충성 감염병은 발생 빈도가 낮아 모델 안정성이 제한적임
- 폭우 이후 질병 발생까지의 실제 시차(lag)를 완전히 규명하기 어려움
