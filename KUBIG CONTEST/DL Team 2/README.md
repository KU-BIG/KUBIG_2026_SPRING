# 🧠 ControlNet 기반 스케치 조건 AAC 이미지 생성 시스템 연구  
### 의사소통이 어려운 환자를 위한 스케치 기반 의미 확장 모델

---

## 📖 프로젝트 개요

이 프로젝트는 **언어적 의사소통이 어려운 환자**를 위한 스케치 기반 이미지 생성 시스템을 탐색하는 연구야.

환자는 복잡한 문장을 말하기는 어렵지만, 단순한 낙서는 그릴 수 있는 경우가 있어.  
우리는 이런 스케치를 입력으로 받아,

- 구조는 최대한 유지하고  
- 의미를 보강해서  
- 의료진이 이해할 수 있는 이미지로 확장하는 게 가능한지 실험했어.

이를 위해 **Stable Diffusion + ControlNet** 기반 조건부 이미지 생성 모델을 사용했어.

---

## 🎯 연구 목적

1. 스케치 품질(환자 중증도)에 따라 적절한 CFG Scale이 달라지는지 분석
2. 스케치가 단계적으로 추가될 때 구조 보존이 유지되는지 검증
3. ControlNet 기반 구조 제어의 한계와 설계 인사이트 도출
