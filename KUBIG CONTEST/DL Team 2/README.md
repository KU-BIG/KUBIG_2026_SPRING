🧠 ControlNet 기반 스케치 조건 AAC 이미지 생성 시스템 연구
의사소통이 어려운 환자를 위한 스케치 기반 의미 확장 모델

📖 프로젝트 개요

본 프로젝트는 언어적 의사소통이 어려운 환자를 위한 스케치 기반 이미지 생성 시스템을 연구한다.

환자는 복잡한 문장 표현은 어렵지만, 단순한 낙서 형태의 그림은 그릴 수 있는 경우가 있다.
본 연구는 이러한 스케치를 입력으로 받아,

구조는 유지하면서

의미를 보강하여

의료진이 이해 가능한 이미지로 확장하는 것이 가능한지 분석한다.

이를 위해 Stable Diffusion + ControlNet 기반 조건부 이미지 생성 모델을 활용하였다.

🎯 연구 목적

스케치 품질(환자 중증도)에 따라 적절한 CFG Scale이 달라지는지 분석

누적 스케치 상황에서 구조 보존이 유지되는지 검증

ControlNet 기반 구조 제어의 한계 및 설계 인사이트 도출

🏗 시스템 구조
환자 스케치 입력
        ↓
전처리 (Grayscale → Resize → Edge/Scribble 변환)
        ↓
ControlNet (구조 조건 주입)
        ↓
Stable Diffusion v1.5 (의미 생성, CFG 조절)
        ↓
생성 이미지 출력
사용 기술

Stable Diffusion v1.5

확산 기반 이미지 생성 모델

텍스트 프롬프트를 통해 의미 생성

CFG(Classifier-Free Guidance)로 텍스트 영향력 조절

ControlNet (Scribble)

입력 스케치의 구조를 조건으로 사용하는 보조 네트워크

생성 이미지가 원래 스케치를 따르도록 유도

🔍 주요 인사이트

CFG Scale은 구조–의미 균형에 중요한 영향을 미친다.

누적 스케치 상황에서 구조 보존은 불안정해질 수 있다.

단일 최종 이미지 제공은 오해를 유발할 가능성이 있다.

단계별 생성 결과를 함께 제공하는 UI 설계가 필요하다.
