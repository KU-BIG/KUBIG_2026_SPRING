# 🧠 ControlNet 기반 스케치 조건 AAC 이미지 생성 시스템 연구  
### 의사소통이 어려운 환자를 위한 스케치 기반 의미 확장 모델



## 1. 연구 개요

본 프로젝트는 언어적 의사소통이 어려운 환자를 위한 스케치 기반 이미지 생성 시스템의 가능성을 탐색하는 연구이다.

환자는 복잡한 문장을 표현하기 어려운 상황에서도 단순한 낙서는 그릴 수 있는 경우가 존재한다. 본 연구는 이러한 스케치를 입력으로 받아, 구조는 유지하면서 의미를 보강한 이미지를 생성함으로써 의료진이 보다 직관적으로 의도를 이해할 수 있도록 하는 것을 목표로 한다.

이를 위해 Stable Diffusion v1.5와 ControlNet(Scribble)을 결합한 조건부 이미지 생성 모델을 활용하였다.



## 2. 연구 목적

본 연구의 목적은 다음과 같다.

1. 스케치 품질(환자 중증도)에 따라 적절한 CFG Scale 범위가 달라지는지 분석한다.
2. 스케치가 단계적으로 추가되는 상황에서 구조 보존이 유지되는지 검증한다.
3. ControlNet 기반 구조 제어의 안정성과 한계를 분석하고, 향후 시스템 설계 방향을 도출한다.



## 3. 시스템 구조

본 시스템은 다음과 같은 파이프라인을 따른다.

환자 스케치 입력
↓
전처리 (Grayscale 변환 → Resize → Edge/Scribble 변환)
↓
ControlNet (구조 조건 주입)
↓
Stable Diffusion v1.5 (의미 생성, CFG 조절)
↓
생성 이미지 출력


- **Stable Diffusion v1.5**는 확산 기반 이미지 생성 모델로, 텍스트 프롬프트를 기반으로 의미를 생성한다.
- **ControlNet (Scribble)**은 입력 스케치의 구조를 조건으로 활용하여 생성 이미지가 원래 형태를 따르도록 유도한다.
- **CFG (Classifier-Free Guidance)**는 텍스트 프롬프트의 영향력을 조절하는 파라미터로, 구조와 의미 간 균형에 중요한 역할을 한다.



## 4. 실험 1 — CFG Scale 안정성 분석

### 4.1 연구 질문

스케치 품질에 따라 최적 CFG Scale 범위가 달라지는가?

### 4.2 실험 방법

- 고정 변수:
  - 입력 스케치
  - 텍스트 프롬프트
  - 랜덤 시드
- 변경 변수:
  - `guidance_scale` (3.0 / 7.0 / 12.0)

생성 이미지의 구조 유지 여부, 의미 명확성, 왜곡 정도를 비교 분석하였다.

### 4.3 실험 결과

- 낮은 CFG:
  - 구조는 비교적 안정적으로 유지됨
  - 의미 확장은 제한적임
- 중간 CFG:
  - 구조와 의미의 균형이 가장 안정적으로 나타남
- 높은 CFG:
  - 의미 표현은 풍부해지나, 구조 왜곡 가능성 증가

### 4.4 결론

스케치 품질에 따라 CFG 조절 정책을 설정할 수 있는 가능성을 확인하였다.



## 5. 실험 2 — 누적 스케치 기반 구조 보존 검증

### 5.1 연구 질문

스케치가 단계적으로 추가될 경우, 생성 모델은 구조와 의미를 안정적으로 유지할 수 있는가?

### 5.2 실험 시나리오 예시

사례: “천장 형광등이 눈부시다”

- Step 1: 전구
- Step 2: 전구 + 눈
- Step 3: 전구 + 눈 + 번개 표시(통증 표현)

### 5.3 실험 결과

- Step 1–2:
  - 비교적 안정적인 구조 유지
- Step 3:
  - 구조 붕괴 및 의미의 과도한 재해석 발생

또한 사회적·추상적 의미(예: 면회 제한)의 경우, 생성 이미지 왜곡 현상이 더욱 두드러지게 나타났다.

### 5.4 결론

의미가 누적되고 복잡해질수록 구조 제어 안정성이 감소하는 한계를 확인하였다.



## 6. 주요 인사이트

1. CFG Scale은 구조–의미 균형에 핵심적인 영향을 미친다.
2. 누적 스케치 상황에서는 ControlNet 기반 구조 제어의 한계가 나타난다.
3. 단일 최종 이미지 결과만 제공하는 방식은 의도 왜곡 가능성을 내포한다.
4. 단계별 생성 결과를 함께 제공하는 인터페이스 설계가 필요하다.



## 7. 향후 연구 방향

- 스케치 복잡도 기반 자동 CFG 추정 모델 개발
- ControlNet conditioning scale의 세분화 조정
- 상징 기호(번개, 정지표지 등)를 오버레이 방식으로 처리하는 하이브리드 접근
- 단계별 결과 저장 및 해석 중심 UI 설계
- 의료진 대상 의미 전달 정확도 평가
